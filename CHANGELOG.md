# PrettyTooltip 1.1.0

- Added styled macro tooltips, including spell and item previews
  selected through #showtooltip.
- Added pet ability, command, and stance tooltips, with autocast
  and active-state indicators.
- Added styled minimap tooltips.
- Added flight path tooltips showing the destination, zone,
  travel cost, and current location.
- Improved spell school detection with a dedicated database
  covering WoW Forever spells and Frostfire Bolt.
- Expanded spell damage and healing breakdowns and fixed
  talent tooltip layouts.
- Added markers for use effects, chance-on-hit effects, and
  enchants, plus number highlighting for use and proc effects.
- Improved bag tooltip handling and parsing of bonuses
  against specific creature types.
- Expanded style controls with padding, minimum width,
  Blizzard borders, and individual reset buttons; refined
  badges and item level icons.
- Added font string caching for faster drawing, and addon
  memory reporting in /ptip perf.
