# PrettyTooltip art

`stat-marker.tga` is a 32 x 32 RGBA diamond drawn as a texture so it does not depend on the player's font glyph coverage.

`glow.tga` is a 64 x 64 white halo with a smooth falloff, generated by `make_glow.py`. The panel draws it behind its body as a 9-slice, tinted by item quality and blended additively.

`logo.tga` is the 64 x 64 addon list icon, a miniature of the item panel, generated by `make_logo.py`.
