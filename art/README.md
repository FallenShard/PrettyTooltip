# PrettyTooltip art

`quality-corner-source.png` is the transparent source generated with the built-in imagegen tool. `quality-corner.tga` is its 256 x 256 RGBA game texture. The addon tints this neutral silver ornament green, blue, purple, or orange for uncommon, rare, epic, and legendary items.

Generation prompt: "Create one transparent, neutral silver-white high-fantasy tooltip corner ornament. Use crisp L-shaped engraved metal filigree with a curling leaf and tapered ends. It must remain readable at 28 x 28 pixels. No border frame, icon, gemstone, text, background, or watermark."

`stat-marker.tga` is a 32 x 32 RGBA diamond drawn as a texture so it does not depend on the player's font glyph coverage.
