# PrettyTooltip art

`stat-marker.tga` is a 32 x 32 RGBA diamond drawn as a texture so it does not depend on the player's font glyph coverage.

`glow.tga` is a 64 x 64 white halo with a smooth falloff, generated by `make_glow.py`. The panel draws it behind its body as a 9-slice, tinted by item quality and blended additively. `band.tga` is the same falloff at 48 x 48 with a 16-texel margin and a plain smoothstep curve (`make_glow.py --size 48 --margin 16 --power 1 --out band.tga`); on the textured backdrop it feathers the header and footer tint bands so they fade in from the rim.

`faction-alliance.tga` and `faction-horde.tga` are the faction watermarks on player panels: 256 x 256 white silhouettes, each emblem fitted to 224 px on its longer side and centered, so both are handled the same way; the addon tints them. `make_faction.py` makes them from emblem images of any size (`python make_faction.py alliance.png faction-alliance.tga`).

`logo.tga` is the 64 x 64 addon list icon, a miniature of the item panel, generated by `make_logo.py`. `logo-400.png` is the same design at 400 x 400 for the CurseForge project avatar (`make_logo.py --size 400 --out logo-400.png`); it is not packaged.
